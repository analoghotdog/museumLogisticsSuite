The Pipeline

Three focused tools, one shared data spine. Each tool exports a clm/1 manifest (Send to Suite) that the next tool loads (Load Manifest). Files travel by download/upload — no server needed. When the tools are open in the same browser, a manifest also passes automatically: look for the 📥 banner in the receiving tool.

Notes

  • Keep all four files in the same folder — the tools link to each other.
  • Open each tool once with internet available (three.js / fonts load from CDN), after that they run offline.
  • CaPackyBara object images live in a folder named after the import file + _Media — beside the HTML file, or picked from disk with Images Folder (local) so the data never has to be published.
  • Shared library clm-library.js (not loaded) supplies boxes, store presets, tray footprints, crate sizes and vehicle presets to all tools — edit it to change them everywhere.
  • All dimensions are millimetres; manifest containers marked external carry outer dims (walls/base/lid included) — that's what fits on a shelf or in a car.
  • The manifest is the contract; browser storage is only a convenience. Details in README.md.
