Packing Guide

Understanding CaPackyBara Parameters

1. Data Input

Two formats are accepted. Both UTF-8 and UTF-16 files load without fuss.

  • Museum TSV export: Columns are Object short summary · Nomenclature Classification Category · [...]
  • Plain CSV: Columns are name, type, length_mm, width_mm, height_mm.
  • Image refs: Images sit in a folder named after your import file, extension included, with _Media
  • Missing dimensions: Any object without a length or width takes the assumed size set under Data Input (50 mm by default).

2. Internal Item Padding

This is the protective buffer around each object before it goes into a tray. Choose one of two strategies.

Proportional Strategy Padding is a percentage of the object's dimensions, held between Min Pad and Max Pad. Larger objects get more room, and nothing gets an unreasonable amount.
Flat Strategy The same fixed millimetre value goes on every side, whatever the size of the object. Simple and predictable.
  • Padded L × W: The two longest dimensions, laid flat, plus (2 × Side Padding).
  • Padded H: The shortest dimension, standing vertically, plus Depth Pad and Lid Clearance.
  • Depth Pad: Extra foam or base material under the object.
  • Lid Clearance: Gap to the lid of the tray, keeps pressure off the item.

3. Type Height Defaults

If a row has no height, CaPackyBara guesses it based on the object type. Adjust the defaults, or add new types.

  • The Fallback is the height for any type not in the list.
  • Types are case-insensitive and trimmed.

4. Tray Inventory & Depths

Tell CaPackyBara which tray depths (internal heights) are in stock and how many of each.

  • Format: 50:3, 100:4, 150:2, 200
  • 50:3 → 3 trays of 50 mm depth
  • 200 → unlimited trays of 200 mm depth (no count = infinite)
  • Leave blank to permit CaPackyBara to custom-size trays as needed.

5. Tray Footprints

The internal L × W of each tray style you have available. CaPackyBara will pack objects into these, stacking depth.

  • ClipCrate: 895 × 790 mm is the standard.
  • Add more sizes if you use different trays or have custom footprints.

6. Structural Thickness & Crate Allowances

These build the external dimensions of each tray and crate from the item placements.

  • Tray side walls: Material thickness on the tray perimeter (usually 18 mm).
  • Tray base: Bottom support (usually 18 mm).
  • Tray lid: Lid thickness if trays have lids (0 if open-top).
  • Crate side walls: Spacing for crate walls around the packed trays.
  • Crate base board: Heavy timber or platform under the crate (usually 150 mm).
  • Crate interlayer: Cardboard or plywood between stacked trays inside a crate.
  • Crate top clearance: Space for lid or tie-down (usually 18 mm).

7. Consolidation Rules

After packing, trays with low utilization can be merged to reduce waste.

  • Min util. before merge: If a tray is below this %, it becomes a candidate for merging.
  • Cross-type fill: Allows objects of different types to be packed together in the same tray.
  • Max depth variance: Trays being merged must have depths within this range (in mm).

8. Reading the Results

After you Run CaPackyBara:

  • 3D Visualization: Rotate, zoom, pan to inspect the load.
  • Results Table: A row per item, showing which crate, tray, and position it occupies.
  • Tray Layouts: Top-down diagrams of each tray. Drag items to rearrange, double-click to rotate.
  • Export Trays as PDF: Print-friendly pages: one tray diagram per page, followed by an items list for that tray.
